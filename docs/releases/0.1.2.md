# Caisson 0.1.2

在 `0.1.1` 基础上增加插件市场和命令行环境配置。

## 新增

- 首次启动时自动将 `dshmarket` 安装到用户的 DSH Web profile。
- 安装时将内置 DSH CLI 的 `.bin` 目录加入当前用户 PATH。
- 重复启动和重复安装保持幂等，不重复添加插件或 PATH 条目。

## 继承功能

- 自包含 Windows x64 安装包。
- Electron 原生窗口、系统托盘、单实例和关闭到托盘。
- 自动启动或复用本机 `dsh web` 服务。
- 逐模型 reasoning effort 编辑器和模型列表“取消全部”按钮。

---

## English

Adds plugin-market bootstrapping and command-line environment setup on top of `0.1.1`.

### Features

- Installs `dshmarket` into the user's DSH Web profile on first launch.
- Adds the bundled DSH CLI `.bin` directory to the current user's PATH.
- Keeps plugin installation and PATH configuration idempotent across repeated runs.

### Included from 0.1.1

- Self-contained Windows x64 installer.
- Native Electron window, system tray, single-instance behavior, and close-to-tray.
- Starts the bundled `dsh web` service or attaches to an existing local service.
- Per-model reasoning-effort settings and the custom-provider deselect-all action.
