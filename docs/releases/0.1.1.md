# Caisson 0.1.1

Caisson 的首个标准 SemVer 版本，基于 DeepSeek Harness `0.1.0-rc.6`。

## 功能

- 自包含 Windows x64 安装包，无需预装 Node.js 或 DSH。
- 原生 Electron 窗口、系统托盘、单实例和关闭到托盘。
- 自动启动或复用本机 `dsh web` 服务。
- 设置页支持逐模型配置 reasoning effort。
- 自定义模型供应商列表支持一键取消全部选择。

## 安装说明

- 支持 Windows 10/11 x64。
- 安装包未签名，Windows SmartScreen 可能显示未知发布者。
- 模型 API Key 不包含在安装包中，需要首次启动后自行配置。

## English

Caisson's first standard SemVer release, based on DeepSeek Harness `0.1.0-rc.6`.

### Features

- Self-contained Windows x64 installer with no system Node.js or DSH requirement.
- Native Electron window, system tray, single-instance behavior, and close-to-tray.
- Starts the bundled `dsh web` service or attaches to an existing local service.
- Per-model reasoning-effort settings.
- Deselect-all action for custom provider model lists.

### Installation Notes

- Windows 10/11 x64 only.
- The installer is unsigned, so Windows SmartScreen may show an unknown publisher warning.
- Model API keys are not bundled and must be configured after the first launch.
