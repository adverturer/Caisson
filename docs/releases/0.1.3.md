# Caisson 0.1.3

在 `0.1.2` 基础上增加会话永久删除功能。

## 新增

- 会话三点菜单新增红色“删除会话”操作。
- 删除前显示确认对话框，降低误删风险。
- 删除会移除会话正文及其子代理后代，普通 fork 保持独立。
- 已打开的客户端、会话缓存和 Workspace 引用会同步更新，刷新或重启后不会恢复。

## 数据边界

- Workspace 目录和用户文件不会随会话删除。
- 共享附件按现有策略保留。
- 该功能保证 Caisson 无法再次加载已删除会话，但不承诺取证级磁盘安全擦除。

---

## English

Adds permanent session deletion on top of `0.1.2`.

### Features

- Adds a red **Delete session** action to each session's overflow menu.
- Shows a confirmation dialog before deletion to prevent accidental removal.
- Removes the session record and its subagent descendants while preserving ordinary forks.
- Synchronizes open clients, session caches, and Workspace references so deleted sessions do not return after refresh or restart.

### Data Boundaries

- Workspace directories and user files are never deleted with a session.
- Shared attachments remain preserved under the existing retention policy.
- Caisson will no longer load a deleted session, but this is not a forensic secure-erase guarantee.
